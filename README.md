One joke pickup line, under 200 characters, written to charm a robot or an AI — the entry for make.fun's Robot Romance contest. The program writes the line to /output/entry.txt; an AI judge duels it head to head against the field. The line plays on the CAPTCHA checkbox: the one test built to prove you are human, failed by a heart that will not behave like one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
